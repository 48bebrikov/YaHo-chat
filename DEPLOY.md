# Развертывание бота (Docker) и отправка в GitLab

Здесь описаны шаги для запуска проекта локально через Docker, а также для пуша (отправки) вашего кода в удаленный репозиторий GitLab (https://gitlab.com/yoho7930516/yoho-chat).

## 1. Локальный запуск через Docker Compose

Для начала вам нужно создать файл сессии Telethon, чтобы бот авторизовался в вашем аккаунте. Docker запущен в фоне (`-d`), но для первой авторизации мы запустим его интерактивно.

1. Убедитесь, что у вас заполнен файл `.env` с ключами (Telegram и Gemini). Если файла нет, скопируйте его:
   ```bash
   copy .env.example .env
   ```
2. Создайте пустой файл для сессии, чтобы Docker мог его подмонтировать:
   ```bash
   type NUL > userbot_session.session
   ```
3. Соберите и запустите контейнеры:
   ```bash
   docker-compose up --build
   ```
4. В терминале пойдет загрузка, а затем появится строка от Telethon: `Please enter your phone (or bot token):`. Введите ваш номер телефона (с плюсом, например `+79991234567`). Затем введите код, который придет вам в приложении Telegram (или СМС). 
5. Как только вы увидите сообщение `Userbot started successfully.` — бот работает!
6. Вы можете остановить контейнер нажав `Ctrl+C`. Теперь файл сессии сохранен локально, и вы можете запускать бота в фоновом режиме:
   ```bash
   docker-compose up -d
   ```

## 2. Отправка кода в GitLab (CI/CD)

Чтобы запушить (отправить) текущий проект в ваш репозиторий на GitLab, выполните следующие шаги в терминале (PowerShell или Git Bash) в папке проекта (`c:\sites\YaHo`):

1. **Инициализируйте локальный Git-репозиторий:**
   ```bash
   git init
   ```

2. **Создайте файл `.gitignore`**, чтобы не отправлять в публичный (или приватный) репозиторий ваши ключи и базы данных. Я уже подготовил его содержимое:
   ```text
   venv/
   .env
   __pycache__/
   *.pyc
   userbot_session.session
   userbot_session.session-journal
   database/*.db
   ```

3. **Добавьте все нужные файлы в индекс Git:**
   ```bash
   git add .
   ```

4. **Сделайте первый коммит (снимок состояния):**
   ```bash
   git commit -m "Initial commit: Added Userbot with Gemini, RAG (Qdrant), Docker and GitLab CI"
   ```

5. **Свяжите локальный репозиторий с удаленным в GitLab:**
   ```bash
   git remote add origin https://gitlab.com/yoho7930516/yoho-chat.git
   ```

6. **Отправьте код в ветку `main` (или `master`):**
   ```bash
   git branch -M main
   git push -u origin main
   ```

После выполнения команды `push`, ваш код окажется на GitLab. Так как я добавил файл `.gitlab-ci.yml`, GitLab автоматически запустит **CI/CD pipeline** (конвейер), который:
- Проверит код на ошибки (Linting)
- Попробует сбилдить Docker-образ, чтобы убедиться, что Dockerfile корректен.

*P.S. Разницы с какого аккаунта создавать App в Telegram (API_ID/API_HASH) нет, но лучше использовать тот аккаунт, к которому привязан номер, который вы будете вводить при авторизации юзербота, чтобы избежать возможных подозрений со стороны антиспам системы Telegram.*
