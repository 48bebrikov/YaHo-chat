# YaHo-chat

YaHo-chat — это умный Telegram-юзербот (AI Friend), построенный на базе библиотеки Telethon и нейросети Google Gemini. Бот умеет общаться как живой человек, запоминать контекст бесед (благодаря RAG и векторной базе данных Qdrant), искать информацию в интернете и даже читать содержимое веб-страниц.

## Основные возможности

*   **Интеграция с Google Gemini:** Использование мощной языковой модели для генерации осмысленных, контекстных и естественных ответов.
*   **Долгосрочная память (RAG):** Бот запоминает важные детали из прошлых разговоров, сохраняя их в векторную базу данных Qdrant, и использует этот контекст в будущих беседах.
*   **Использование инструментов (Tools):**
    *   Поиск в интернете (через DuckDuckGo).
    *   Чтение содержимого веб-страниц (парсинг текста).
    *   Работа с PDF-документами (через Playwright).
*   **Имитация живого общения:**
    *   Случайные задержки перед прочтением сообщений (имитация того, что человек не всегда онлайн).
    *   Имитация набора текста (`typing...`).
    *   Разбиение длинных ответов на несколько коротких сообщений.
    *   "Ночная тишина" (бот не отвечает мгновенно ночью, имитируя сон).
*   **Мониторинг и метрики:** Встроенная поддержка Prometheus и Grafana для отслеживания состояния бота и статистики сообщений.
*   **Контейнеризация:** Полностью готов к запуску через Docker и Docker Compose.

## Технологический стек

*   **Язык:** Python 3.11+
*   **Telegram API:** Telethon
*   **LLM:** `google-genai` (Google Gemini)
*   **Векторная БД:** Qdrant (`qdrant-client`)
*   **Эмбеддинги:** `sentence-transformers` (модель `deepvk/USER-bge-m3`)
*   **Поиск и парсинг:** `ddgs`, `httpx`, `playwright`
*   **Мониторинг:** Prometheus, Grafana, Loki, Promtail

## Установка и запуск (Локально через Docker)

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/48bebrikov/YaHo-chat.git
    cd YaHo-chat
    ```

2.  **Настройте переменные окружения:**
    Создайте файл `.env` в корне проекта и заполните его своими данными (см. пример в `DEPLOY.md`):
    ```env
    API_ID=ваш_api_id
    API_HASH=ваш_api_hash
    GEMINI_API_KEY=ваш_gemini_ключ
    QDRANT_HOST=qdrant
    QDRANT_PORT=6333
    POLL_INTERVAL_SECONDS=3600
    MONITORED_CHANNELS=telegram,durov
    FRIENDS_LIST=username1,username2
    ```
    *Получить `API_ID` и `API_HASH` можно на [my.telegram.org](https://my.telegram.org).*

3.  **Создайте пустой файл сессии:**
    ```bash
    touch userbot_session.session
    ```

4.  **Первый запуск (Авторизация):**
    Запустите контейнеры в интерактивном режиме, чтобы ввести номер телефона и код из Telegram:
    ```bash
    docker compose up --build
    ```
    Следуйте инструкциям в консоли. После успешной авторизации остановите процесс (`Ctrl+C`).

5.  **Запуск в фоновом режиме:**
    ```bash
    docker compose up -d
    ```

## Безопасность

Файлы `.env` и `userbot_session.session` (содержащие ключи API и доступ к вашему Telegram-аккаунту) добавлены в `.gitignore` и **никогда не должны публиковаться в открытом доступе**.
