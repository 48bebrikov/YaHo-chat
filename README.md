# YaHo-chat

YaHo-chat — это умный Telegram-юзербот (AI Friend), построенный на базе библиотеки Telethon. В качестве основного мозга используется любая LLM через OpenRouter (по умолчанию Moonshot Kimi), а для голосовых сообщений — Google Gemini TTS. Бот умеет общаться как живой человек, запоминать контекст бесед (благодаря RAG и векторной базе данных Qdrant), читать и пересылать посты Telegram-каналов, на которые подписан, искать информацию в интернете и даже читать содержимое веб-страниц.

## Основные возможности

- **Интеграция с OpenRouter (LLM) и Gemini (TTS):** Использование мощных языковых моделей (Claude, DeepSeek, Kimi и др.) для генерации осмысленных, контекстных и естественных ответов.
- **Долгосрочная память (Memory Graph & RAG):** Фоновый процесс анализирует диалоги с помощью LangGraph, вытаскивает факты о пользователе и сохраняет их в векторную базу данных Qdrant.
- **Использование инструментов (ReAct Агент):**
  - Поиск в интернете (через высокоточный Tavily API).
  - Чтение содержимого веб-страниц (парсинг текста).
  - Работа с PDF-документами (через Playwright).
  - Python Code Interpreter: Бот умеет выполнять Python-код на лету для расчетов и обработки данных.
  - Установка напоминаний: Бот может устанавливать таймеры и проактивно писать пользователю, чтобы напомнить о делах.
- **Имитация живого общения:**
  - Голосовые сообщения (Gemini TTS): Бот умеет генерировать реалистичные аудиосообщения с эмоциями (смех, шепот, грусть) через Google TTS.
  - Динамическое ожидание набора: Бот не перебьет вас — он отслеживает статус `typing...` в Telegram и дожидается, пока вы полностью закончите мысль, прежде чем отвечать.
  - Имитация набора текста (`typing...`) и записи голосовых.
  - Разбиение длинных ответов на несколько коротких сообщений.
  - "Ночная тишина" (бот не отвечает мгновенно ночью, имитируя сон).
- **Мониторинг и метрики:** Встроенная поддержка Prometheus и Grafana для отслеживания состояния бота и статистики сообщений.
- **Контейнеризация:** Полностью готов к запуску через Docker и Docker Compose.

## Технологический стек

- **Язык:** Python 3.11+
- **Telegram API:** Telethon
- **Агентская архитектура:** LangChain и LangGraph (ReAct StateGraph)
- **LLM:** `langchain-openai` (OpenRouter API), `google-genai` (Gemini TTS)
- **Векторная БД:** Qdrant (`qdrant-client`)
- **Эмбеддинги:** `sentence-transformers` (модель `deepvk/USER-bge-m3`)
- **Поиск и парсинг:** `httpx` (Tavily API), `ddgs` (YouTube), `playwright`
- **Мониторинг:** Prometheus, Grafana, Loki, Promtail

## Установка и запуск (Локально через Docker)

1. **Клонируйте репозиторий:**
  ```bash
    git clone https://github.com/48bebrikov/YaHo-chat.git
    cd YaHo-chat
  ```
2. **Настройте переменные окружения:**
  Создайте файл `.env` в корне проекта и заполните его своими данными (см. пример в `DEPLOY.md`):
    *Получить `API_ID` и `API_HASH` можно на [my.telegram.org](https://my.telegram.org).*
3. **Создайте пустой файл сессии:**
  ```bash
    touch userbot_session.session
  ```
4. **Первый запуск (Авторизация):**
  Запустите контейнеры в интерактивном режиме, чтобы ввести номер телефона и код из Telegram:
    Следуйте инструкциям в консоли. После успешной авторизации остановите процесс (`Ctrl+C`).
5. **Запуск в фоновом режиме:**
  ```bash
    docker compose up -d
  ```

Файлы `.env` и `userbot_session.session` (содержащие ключи API и доступ к вашему Telegram-аккаунту) добавлены в `.gitignore` и **никогда не должны публиковаться в открытом доступе**.
